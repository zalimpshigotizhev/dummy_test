## Как запустить проект

### Сервер:

1. Создайте виртуальные переменные в файле `.env` в корне проекта:

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=demo
DB_USER=postgres
DB_PASSWORD=552216742
```

2. Установите зависимости:

```
python -m venv venv
. .\.venv\Scripts\activate
pip install -r requirements.txt
```

3. С помощью `uvicorn` запустите сервер, находясь в корне проекта:

```
uvicorn DummyMessager:app --reload --host 0.0.0.0 --port 8000
```

### Клиент:

1. Запустите с двух разных терминалов два процесса:

**Terminal 1:**
```
uvicorn DummyMessager:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2:**
```
uvicorn DummyMessager:app --reload --host 0.0.0.0 --port 8001
```

2. Запустите `TestDummyMessager.py`:
```
python .\TestDummyMessager.py
```

## Стек
`Python 3.10` `PostgreSQL`

## Как я решил поставленные задачи

**Сервер:**
**В ответе на запрос не должны присутствовать сообщения, полученные после текущего запроса**
  
Да, действительно. Возвращается информация на данный момент времени.
- ** В ответе на запрос не должны пропускаться сообщения **
  
Таких ситуаций происходить не должно, так как я отлавливаю каждую ошибку, до тех пор, пока запись не добавится в БД с выполнением всех условий.
- ** Порядковые номера сообщений не должны совпадать  **
  Они не совпадают, потому что я использовал встроенную функциональность при объявлении колонок (автоинкрементация).
- ** У сообщений от одного пользователя не должны совпадать счётчики сообщений   **
  Они не совпадают, потому что я использовал ограничение по уникальности при объявлении колонок.

**Клиент:**
- Сервер обрабатывает 5 тысяч запросов в двух запущенных процессах в районе `78 сек` учитывая все ограничения.
